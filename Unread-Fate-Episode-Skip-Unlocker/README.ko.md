# Unread Fate Episode Skip Unlocker

미감상 페이트 에피소드의 대사에서도 기존 스킵 버튼을 사용할 수 있게 해주는 모드입니다.

[English](README.md)

**마지막 테스트:** 2026년 11월 7일 — 게임 버전 2.0.6.

## 안전성 및 호환성

- 미감상 페이트 에피소드 대사의 스킵을 활성화하는 데 필요한 조건만 변경합니다.
- 게임의 기존 스킵 및 완료 처리 과정을 사용하며, 세이브 파일을 직접 수정하거나 보상을 강제로 지급하지 않습니다.
- 후킹을 적용하기 전에 게임 실행 파일과 대상 함수를 검사합니다. 검증에 실패하면 후킹을 설치하지 않습니다.
- 모드 적용 조건에 해당하지 않는 경우 원래 결과를 그대로 사용합니다.

## 테스트 및 제한사항

게임 버전 2.0.6에서 개발하고 테스트했습니다. 대부분의 페이트 에피소드를 다음과 같은 다양한 상황에서 테스트했습니다.

- 여러 캐릭터의 미감상 및 완료한 에피소드
- 대화 중간의 스킵과 전투가 포함된 에피소드
- 에피소드 완료 보상과 게임 재실행 후 저장된 진행 상황
- 모드를 비활성화한 후 게임의 정상 동작

전투 전 대사는 스킵할 수 있지만, 현재 전투와 전투 후 대사는 스킵할 수 없습니다.

## 업데이트 계획

현재 개발 중인 모드 프로젝트가 완료되면 전투 후 대사 스킵 작업을 재개할 예정입니다.

## 필수 구성 요소

- Granblue Fantasy: Relink
- [Reloaded-II](https://github.com/Reloaded-Project/Reloaded-II)
- [Endless Ragnarok Mod Loader](https://www.nexusmods.com/granbluefantasyrelink/mods/526)

## 설치

1. 게임을 종료합니다.
2. Reloaded-II에서 모드 ZIP을 설치하고 모드와 필수 의존성을 활성화합니다.
3. Reloaded-II를 통해 게임을 실행합니다.

모드를 삭제하거나 완전히 비활성화하려면 먼저 게임을 종료하세요. 게임 실행 중 완전한 언로드는 지원하지 않습니다.

## 소스

이 폴더는 로컬 C# 프로젝트와 설정, 테스트 소스를 보관합니다. 로컬 Release DLL은 배포 ZIP의 DLL과 일치합니다. 해당 DLL을 빌드한 정확한 Git 소스 커밋은 기록되어 있지 않으며, 새로 빌드한 파일이 배포본과 바이트 단위로 동일하다고 보장할 수 없습니다.

프로젝트는 .NET 9을 대상으로 하며 로컬에 설치된 Reloaded-II 어셈블리를 참조합니다. 이 폴더에서 `dotnet run --project Tests/FateSkip.Tests.csproj -c Release`로 테스트 프로젝트를 실행할 수 있습니다.

## 개발 및 AI 사용 안내

이 모드는 Codex의 도움을 받아 개발했습니다. 제가 목표와 요구사항을 정하고,
기존 분석 자료와 개발 환경을 제공하며, 개발 과정을 이끌고 게임 내 테스트를
수행했습니다.

Codex는 REA 도구를 이용해 리버스 엔지니어링과 실행 중 분석을 수행하고,
스킵 기능과 관련된 조건을 찾아 모드 코드 대부분을 작성했습니다. 개발 과정에서
테스트 관찰 내용과 결과도 함께 검토했습니다.
