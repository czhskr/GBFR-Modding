# Fate Episode Skip Unlocker

Enables the game's existing Skip function for unread Fate Episodes in Granblue Fantasy: Relink – Endless Ragnarok, without altering the original Skip system.

그랑블루 판타지: 리링크 - 엔드리스 라그나로크에서 미감상 페이트 에피소드에도 게임의 기존 스킵 기능을 사용할 수 있도록 합니다. 기존 스킵 시스템 자체는 변경하지 않습니다.

## Features

- Enables the usual Skip input during unread Fate Episode dialogue.
- Uses the game's existing Skip confirmation and completion flow.
- Does not directly edit save files or force rewards.

## Limitations

- Pre-battle dialogue can be skipped, but battles and post-battle dialogue cannot.
- The mod has been tested with specific Fate Episodes; not every episode has
  been individually verified.
- The mod may not work with unsupported game versions.

# 기능

- 미감상 페이트 에피소드의 대사에서 기존 스킵 입력을 활성화합니다.
- 게임의 기존 스킵 확인창과 완료 처리 과정을 사용합니다.
- 세이브 파일을 직접 수정하거나 보상을 강제로 지급하지 않습니다.

## 제한사항

- 전투 전 대사는 스킵할 수 있지만, 전투와 전투 후 대사는 스킵할 수 없습니다.
- 일부 페이트 에피소드에서 테스트했으며, 모든 에피소드를 개별적으로 확인하지는 않았습니다.
- 지원하지 않는 게임 버전에서는 동작하지 않을 수 있습니다.
