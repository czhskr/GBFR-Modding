# 그랑블루 판타지: 리링크 모드

배포한 모드와 개발 중인 프로젝트를 관리하는 저장소입니다.

[English](README.md)

## 배포한 모드

### Unread Fate Episode Skip

미감상 페이트 에피소드에서도 게임의 기존 스킵 입력을 사용할 수 있게 합니다.

[자세히 보기](Unread-Fate-Episode-Skip-Unlocker/README.ko.md) ·
[Nexus Mods](https://www.nexusmods.com/granbluefantasyrelink/mods/890) ·
[GitHub Releases](https://github.com/czhskr/GBFR-Modding/releases)

### Part Break Indicator

지원하는 록온 부위의 파괴 상태와 검증된 남은 내구도를 표시합니다.

[자세히 보기](Part-Break-Indicator/README.ko.md) ·
[Nexus Mods](https://www.nexusmods.com/granbluefantasyrelink/mods/893) ·
[소스](Part-Break-Indicator/)

소스 보관 범위에는 개발 리소스와 테스트 자료가 포함되지 않습니다. 빌드 및
전체 테스트에는 Reloaded-II 의존성과 별도 로컬 파일이 필요하며, 이 저장소만으로
완전한 모드 패키지를 재현할 수 없습니다.

## 개발

Codex의 도움을 받아 리버스 엔지니어링, 실행 중 분석, 게임 내 테스트를
활용하여 모드를 개발합니다. 각 모드의 개발 과정과 Codex의 기여 범위는
해당 모드의 README에 기록합니다.
