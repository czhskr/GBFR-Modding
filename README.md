# Granblue Fantasy: Relink Mods

Mods for Granblue Fantasy: Relink, including released and in-development projects.

[한국어](README.ko.md)

## Released Mods

### Unread Fate Episode Skip

Enables the game's usual Skip input for unread Fate Episodes.

[Details](Unread-Fate-Episode-Skip-Unlocker/README.md) ·
[Nexus Mods](https://www.nexusmods.com/granbluefantasyrelink/mods/890) ·
[GitHub Releases](https://github.com/czhskr/GBFR-Modding/releases)

### Part Break Indicator

Displays status and verified remaining durability for supported lock-on parts.

[Details](Part-Break-Indicator/README.md) ·
[Nexus Mods](https://www.nexusmods.com/granbluefantasyrelink/mods/893) ·
[Source](Part-Break-Indicator/)

The source archive excludes development assets and test data. Reloaded-II
dependencies and additional local files are required to build and run all tests;
the repository alone cannot reproduce the complete mod package.

## Development

These mods are developed with assistance from Codex, using reverse engineering,
runtime analysis, and in-game testing. Each mod's README describes its
development process and Codex's contributions.
