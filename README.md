# Granblue Fantasy: Relink - Endless Ragnarok Mods

This repository contains my mods for Granblue Fantasy: Relink, including released mods and projects currently in development.

## Mods

### Released

**Unread Fate Episode Skip**

Enables the game's existing Skip function for unread Fate Episodes without altering the original Skip system.

- [Nexus Mods](https://www.nexusmods.com/granbluefantasyrelink/mods/890)

### In Development

I'm currently working on additional mods. I'll add more details as development progresses.

## Development

I develop these mods with assistance from Codex, using reverse engineering, runtime analysis, and in-game testing.

The development process and Codex's contributions may vary between mods. I document relevant details in each mod's README.


이 저장소에는 제가 개발한 그랑블루 판타지: 리링크 - 엔드리스 라그나로크 모드들이 포함되어 있으며, 배포한 모드와 현재 개발 중인 프로젝트를 함께 관리합니다.

## 모드

### 배포 완료

**Fate Episode Skip**

게임의 기존 스킵 시스템을 변경하지 않고, 미감상 페이트 에피소드에서도 스킵 기능을 사용할 수 있도록 합니다.

- [Nexus Mods](https://www.nexusmods.com/granbluefantasyrelink/mods/890)

### 개발 중

현재 추가 모드들을 개발하고 있습니다. 개발 진행 상황에 따라 자세한 내용을 추가할 예정입니다.

## 개발

저는 Codex의 도움을 받아 리버스 엔지니어링, 런타임 분석, 게임 내 테스트 등을 활용하여 모드를 개발하고 있습니다.

개발 과정과 Codex의 기여 범위는 모드마다 다를 수 있으며, 관련 내용은 각 모드의 README에 기록합니다.
