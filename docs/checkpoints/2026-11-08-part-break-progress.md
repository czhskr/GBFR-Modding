## 검증 근거와 한계

- 머리 지원을 추가하기 전 테스트는 `enabled Furycane head unavailable`로 실패했고, 구현 후 21개 테스트 묶음 통과와 빌드 경고/오류 0건을 기록했습니다.
- 독립 전체 후보 코드 검토는 Critical/Important/Minor 모두 0건입니다. 이번 커밋 준비에서는 변경 없는 소스를 재빌드하지 않고 기존 검증 로그·소스·후보 해시의 일치를 확인했습니다.
- 실제 머리에 적용된 피해·파괴·재생과 후보의 게임 내 표시는 아직 미검증입니다. 이 후보는 설치하거나 공개 배포하지 않았습니다.
- 이전 부위 및 공통 UI의 결과를 새 머리의 실전 통과로 간주하지 않습니다.

## 엑스칼리온 조사

- 거골 리액터의 정확한 Em7401 타입, 엑스칼리온 부모 연결, 자체 current/max qword를 확인했습니다.
- 록온 선택 번호는 `-1`이고 실제 유일한 항목의 활성 값은 1입니다. 선택 번호 -1만으로 무조건 록온 해제라고 판단하면 안 됩니다.
- 자연 공격 1회 후 같은 개체의 현재 체력 `1,602,072 → 1,543,653`, 최대값 `1,602,072` 유지를 관찰했습니다. 0을 별도 파괴 완료 플래그로 해석하지 않습니다.
- 사용자가 기본 체력바 자체가 파괴 진행도라고 지적했습니다. 중복 표시의 실익이 낮아 추가 자연 파괴 시험과 모드 지원은 보류했습니다. 다른 엑스칼리온 부속 개체까지 같은 UI라고 일괄 단정하지 않습니다.
- 읽기 관찰기와 테스트를 보존합니다. 새 네 타입의 정확한 타입·ExHp 테이블, 독립 current/max, 0에 임의 파괴 플래그를 만들지 않는 처리, 잘못된 최대값·정밀도 초과 값·오래된 부모·잘못된 테이블의 거부를 확인했습니다.
- 관찰기는 250ms 간격, 최대 15분/1,800개 이벤트이며 후크·대상 네이티브 호출·게임 데이터 쓰기를 하지 않습니다. 자동 읽기 종료와 별개로 스크립트 제거 및 세션 종료가 필요합니다.
- 시험의 스크립트 제거 성공, 연결 종료 응답과 후속 `No open Frida session`을 확인했습니다. 활성 관찰 연결은 없습니다. 원시 캡처와 프로세스 주소는 공개 저장소에 올리지 않습니다.
